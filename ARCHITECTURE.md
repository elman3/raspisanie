# Архитектура Telegram-бота «Расписание»

Бот показывает студенту расписание занятий из Excel-файла.
Диалог: приветствие → программа → группа → день недели → чётная/нечётная неделя → расписание.

Бот написан на C++17 (libcurl + nlohmann/json), создан через BotFather,
получает сообщения методом long polling.

---

## 1. Структура системы

Система состоит из двух частей: **подготовка данных** (запускается при обновлении расписания)
и **сам бот** (работает постоянно).

| Уровень | Компонент | Что делает |
|---|---|---|
| Клиент | Telegram (телефон, ПК, веб) | Студент пишет боту и нажимает inline-кнопки |
| Платформа | Telegram Bot API | Принимает сообщения пользователей и отдаёт их боту как события (Updates) |
| Сервер бота | `schedule_bot` (`bot.cpp`) | Принимает события, строит экраны, фильтрует недели, отправляет ответы |
| Данные | `schedule.json` | Готовое расписание, загружается в память при запуске бота |
| Подготовка данных | `convert_schedule.py` | Читает Excel и создаёт `schedule.json` |
| Источник | `schedule.xls` | Исходный файл расписания от вуза |

### Части внутри бота (`bot.cpp`)

| Часть | Функция в коде | Задача |
|---|---|---|
| Контроллер | `handle()`, `api()` | Получает события через `getUpdates`, отправляет ответы |
| Логика диалога | `render()`, `screen*()` | Определяет, какой экран показать по нажатой кнопке |
| Фильтр недель | `screenSchedule()` | Оставляет занятия нужной недели |
| Данные | `g_db` | `schedule.json` целиком в памяти |

## 2. Схема

```
 ПОДГОТОВКА ДАННЫХ (при обновлении расписания)
 ┌──────────────┐    ┌─────────────────────┐    ┌───────────────┐
 │ schedule.xls │───►│ convert_schedule.py │───►│ schedule.json │
 │ (Excel)      │    │ (парсер, нч/чн)     │    │ (данные)      │
 └──────────────┘    └─────────────────────┘    └───────┬───────┘
                                                        │ загрузка
                                                        │ при старте
 РАБОТА БОТА (постоянно)                                ▼
 ┌────────────┐   ┌──────────┐   ┌──────────┐   ┌───────────────────────────────┐
 │Пользователь│◄─►│ Telegram │◄─►│ Bot API  │◄─►│ schedule_bot (C++)            │
 │            │   │ клиент   │   │ HTTPS    │   │                               │
 └────────────┘   └──────────┘   └──────────┘   │ Контроллер ─► Логика диалога  │
                                                 │                  │            │
                                                 │            Фильтр недель      │
                                                 │                  │            │
                                                 │            Данные (JSON)      │
                                                 └───────────────────────────────┘
```

Во время работы бот обращается только к Telegram Bot API.
Расписание уже лежит в памяти, поэтому ответ приходит мгновенно.

## 3. Поведение системы

### Сценарий пользователя

1. Студент пишет боту (например, `/start`). Бот отвечает приветствием
   «Привет! Хочешь узнать своё расписание?» и кнопкой «Да, хочу!».
2. Бот предлагает **программу** (список берётся из файла).
3. Бот предлагает **группу** выбранной программы (тоже из файла).
4. Бот предлагает **день недели** (понедельник — суббота).
5. Бот спрашивает **неделю**: нечётная (нч) или чётная (чн).
6. Бот показывает расписание. Под ним кнопки:
   «Другая неделя», «Другой день», «В начало».
   На остальных экранах есть кнопка «Назад».

Весь выбор пользователя хранится в самих кнопках (`callback_data`),
поэтому бот отвечает на каждое нажатие независимо от предыдущих
и обслуживает много людей одновременно.

### Сценарий обновления расписания

1. Получить новый Excel-файл.
2. Запустить `python3 convert_schedule.py schedule.xls schedule.json`.
3. Перезапустить бота.

### Правила чётных и нечётных недель

Метка стоит в начале ячейки Excel:

| В ячейке | Когда занятие показывается |
|---|---|
| `нч`, `нч.`, `н.н.` | Только на нечётной неделе |
| `чн`, `чн.`, `ч.н.` | Только на чётной неделе |
| метки нет | На любой неделе |

Метки внутри текста (например, «нч. – 1 п/гр., чн. – 2 п/гр.») не фильтруются.
Такое занятие показывается на обеих неделях с исходным текстом.

### Как конвертер читает Excel

- Программа определяется по названию группы: «25 ИСТ-1-1» → программа «ИСТ».
- Число студентов в конце названия группы («25 ИСТ-1-1 21») отбрасывается.
- Дни недели и пары определяются по строкам, группы по столбцам.
- Лекция на несколько групп (объединённая ячейка) попадает каждой из них.
- Занятие на две пары подряд подписывается как «4–5 пара».

## 4. Взаимосвязи компонентов

| Связь | Протокол | Описание |
|---|---|---|
| Бот ↔ Telegram Bot API | HTTPS, JSON | Бот сам опрашивает API методом `getUpdates` (long polling) |
| Конвертер → бот | Файл `schedule.json` | Бот читает файл один раз при старте |
| Excel → конвертер | Файл `.xls` / `.xlsx` | Конвертер читает файл при запуске |

## 5. Модель данных (`schedule.json`)

Расписание хранится в JSON-файле:

```
programs[]                  программы
  └─ name                   название программы (например, "ИСТ")
  └─ groups[]               группы программы
       └─ name              название группы (например, "25 ИСТ-1-1")
       └─ days{}            день недели → список занятий
            └─ занятие:
                 pair       номер пары (1, 2, 3 ...)
                 pair_end   последняя пара (если занятие идёт две подряд)
                 time       время начала ("8:00")
                 week       "both" | "odd" | "even"
                 text       аудитория, предмет, тип и преподаватель одной строкой
```

Предмет, преподаватель и аудитория хранятся одной строкой `text`,
так как в Excel это одна ячейка.

## 6. Интерфейсы

### Пользователь (Telegram)
- Любое сообщение (в том числе `/start`) открывает приветствие.
- Inline-кнопки для всех шагов выбора.
- Сообщения с разметкой HTML.

### Telegram Bot API
Используемые методы: `getUpdates`, `deleteWebhook`, `sendMessage`,
`editMessageText`, `answerCallbackQuery`.

Формат `callback_data` (индексы в `schedule.json`):

| Данные | Значение |
|---|---|
| `s` | список программ |
| `p:i` | группы программы `i` |
| `g:i:j` | дни для группы `j` программы `i` |
| `d:i:j:k` | выбор недели для дня `k` |
| `w:i:j:k:n` | расписание, `n` = 1 (нечётная) или 2 (чётная) |

### Командная строка
```
python3 convert_schedule.py schedule.xls schedule.json
BOT_TOKEN=<токен от BotFather> ./schedule_bot schedule.json
```
